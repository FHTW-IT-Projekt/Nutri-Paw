# Register

## setup

1. **installing bcrypt**
To be able to hash passwords we need to use bcrypt.
In the auth.js file it is already imported
To install bcrypt yourself simply type "npm install bcrypt" in the cmd

2. **setting up your enviromet**
To succesfully register someone you need to:
    1. open the XAMPP control panel and start Apache and Mysql for database access
    2. establish a connection to port 3000 by typinng "node server.js" in the cmd (you need to be in the same folder your server.js file is in!)
    3. Golive in VSCode
